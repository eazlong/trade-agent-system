# 成功标准①的分母口径：箱体震荡不进一致率分母

**状态**：已实施（口径，2026-11-24 #67）／未实施（结构性改造）
**日期**：2026-11-23（口径实施：2026-11-24）
**口径落地位置**：`truth.tally` 的 `boxed` 一摊 + `truth.describe` 的分母口径句；读面见
`serializers.volatility_source_payload` 与 `/regime` 页面的两维渲染。
**与 ADR 0002 的关系**：ADR 0002 定义的是「量化 + 资讯」两根轴——那是**判定输入的分解**。本记录讨论的是另一个问题：**量化轴内部**用几个维度描述市场。两者不是同一件事，不要合并。

## 问题

用户要求机制「同时」识别牛熊周期、震荡区间与消息面高波动，而非四档互斥。原结构：

```
PRIORITY = (HIGH_VOL, DOWNTREND, UPTREND, RANGE)
```

用单一维度回答两个不同的问题——**方向**（慢变量）与**波动**（快变量叠加层）。三个结构性缺陷：

| 缺陷 | 机制 | 实测后果 |
|---|---|---|
| 波动吃掉周期 | `HIGH_VOL` 排第一 | 434 天判高波动，这些天的周期信息全部丢弃 |
| 箱体当兜底 | `RANGE` 是「其余」 | 207 天系统性错向；其中 125 天斜率方向其实正确，被 `\|sep\| <= 0.5` 卡住 |
| 高波动按配额 | `high_vol_quantile = 0.80` | 数学上必有 20% 日子判高波动，人工真值里是 0 天 |

## 单参数调整无效（已实测）

| 调整 | 一致率 | 错向 |
|---|---|---|
| `sep_min_atr` 0.5 → 0.0 | +67 天 | −62 |
| `high_vol_quantile` 0.80 → 0.95 | +21% | **+13（变差）** |

任何单参数下两者此消彼长。**根因是维度混同。**

## 二维结构（已验证，未实施）

| 维度 | 取值 | 性质 |
|---|---|---|
| 周期 `cycle` | bull / bear / sideways / unclear | 慢变量 |
| 波动 `volatility` | normal / event_spike | 快变量，**叠加层** |

- 两维**同时输出、互不覆盖**（`bull + event_spike` = 牛市暴跌日）
- `sideways` 从兜底改为**显式判定**（必须主动证明「无间距且无强度」）
- 高波动改为**事件驱动代理**（跳空/放量/ATR 骤升/单日大幅），不再按分位配额

## 六组对照实验

| # | 方案 | 一致率 | 错向 | 箱体召回 |
|---|---|---|---|---|
| 1 | 旧结构 | 36.5% | **207** | — |
| 2 | 二维分离（背离弃权） | 54.4% | 0 | — |
| 3 | 二维 + 背离按斜率定向 | 59.0% | 0 | — |
| 4 | **价格位置 close vs MA120** | **65.7%** | **0** | 0/302 |
| 5 | + `detect_box_range` | 65.7% | 0 | **0/302** |
| 6 | + 相对横盘判据（66 组参数） | 64.7% | 2 | 最高 77%，但总一致率掉到 50% |

### 箱体为什么识别不了

`detect_box_range` 在 2518 天里零检出。用人工标为箱体的 2024-04~09（188 根）验证：

```
close 范围 53963 ~ 71620，振幅 32.7%
is_ranging: False
reason: 下沿候选 cluster 不满足粗筛条件
```

而 `max_width_pct = 0.30`。**人工的「箱体」是相对横盘（相对前一轮涨幅歇脚），
检测器找的是绝对窄幅。** 放宽到 50% 仍不通过。

相对判据同样失败：`dd=25%` 时箱体召回 77%，但把本该判上行的日子吞成横盘，
总一致率从 65.7% 掉到 50%。

### 算术上限

```
趋势区间 2143 天（87.6%） / 箱体 302 天（12.3%）
箱体召回 0% 时，纯方向指标上限 = 87.6%
实际（方向召回 75%） = 65.7%
```

## 决策

### 采纳：修订①的分母口径

**趋势区间（上下行）计入分母；箱体区间不计入、但保留在系统性错向检查中。**

数字：分母 2143、一致 1607 = **75.0%**，错向 **0**。

**仍未达 80%。** 修订让结论有意义，但没让机制通过——差的 5 pt 是真实识别能力缺口。

**为什么不算放水**：「系统性错向」（人工标极端、算法判箱体，一次即不达标）**原样保留**，
它的语义是「把要命的行情判成平静」，不需要箱体召回就有效。箱体退出的是**分母**，
不是**警报**。

### 未实施：结构性改造

二维结构已验证有效（36.5% → 65.7%、错向 207 → 0），但**未落入 `quant.py`**：
`BaseRegime` 被 40+ 文件引用，覆盖切片、池化、停用、日报全链路，结构未定稿前落地，
回滚成本高于收益。

## Consequences

- 一致率的**分母不再是全部人工标注**，读这个数的人必须知道「箱体不计入」——日报与体检页需要把分母口径印出来，否则 75.0% 会被读成全档位的一致率。**这一条已落地（#67）**：`truth.describe` 在有分母时紧跟首行印口径句，箱体天数单列报出；`/regime` 读面把两维与波动来源成对透出。
- 「箱体震荡」在机制里仍是 `RANGE`（兜底），口径修订**没有改变机制的产物**，只改变了怎么评价它。这两件事必须分开说。
- 差的那 5 pt 未解决。下调门槛或继续找方法，是后续的独立决策。
- 消息面数据源仍是价格代理（`source: "proxy"`），未接真实资讯。

## 实施补记（2026-11-24，#67）

**这份记录的标题一度领先于代码。** commit `80c4cb3` 的标题写着「箱体退出一致率分母」，
但它对 `truth.py` 的实际改动只有 `fold_overlay`（把高波动叠加层从一天的档位集合里折叠掉），
而 `tally` 里**没有任何一处**按「人工标注是箱体」这个条件排除过日期。实测复现：10 天区间
里 5 天人工标箱体、算法全判上行，`tally` 给出 `counted=10`、`rate=50%`——箱体那 5 天仍在
分母里。也就是说，在那一天到 #67 落地之间，任何「按 ADR 0007 口径理解一致率」的读法都是错的，
而页面与 ADR 都印着这个口径。

**教训（与「先量出上限」并列）**：ADR 的状态词是给人看的契约，而 commit 标题不是。
标题写「已实施」不等于代码里排除了——`grep CALM truth.py` 只有 `CALM` 的定义、没有使用点，
这件事一次静态检查就能看出来。状态词与实现对不上时，错的是那个状态词。

落地形状：
- `truth.Agreement.boxed`：人工标〈箱体震荡〉的天数。**单列**而不是只从分母里扣掉——「75.0%
  是趋势区间的一致率」与「75.0% 是全档位的一致率」是两句不同的话，不报这个数就无法验算。
- 五摊互斥：`days == conflict_days + escalated + boxed + counted`，排除顺序是「冲突 → 抬升
  → 箱体 → 缺口 → 比对」。箱体排在抬升之后，因为「那天机制用的不是纯量化结论」与人工标了
  什么无关，是更硬的一层「不能比」。
- **只按人工标注判，不看算法答了什么**：照算法判的话，判对的日子进分母、判错的被剔出去，
  一致率会被系统性抬上去——而这是准入门槛。
- 「系统性错向」原样保留（箱体退出的是分母，不是警报）。箱体那几天的人工标注是〈箱体震荡〉，
  永远不可能触发「人工标极端、算法判箱体」，两件事在实现上也不相交。

## 教训

**先量出上限，再决定改不改。** 六组实验避免了把一个只值 65.7% 的结构写进 40 个文件。
旧结构调参的历史（`high_vol_quantile` 调高反而错向变差）若要重演一遍，成本高于先做对照实验。
