# 技术分析

核心判断是**共振**：EMA 趋势、MACD 动量、KDJ 位置、形态突破、成交量——几个信号指向同一方向，信念就有多强。指标清单本身不是结论，共振度才是。

## 步骤

### 1. 获取 K 线

用 `ccxt` 同时拉取 **1D** 与 **4h** 两个周期，每周期 ≥200 根（保证 EMA200 计算完整）。

**完成标准**：两个 DataFrame 已加载，行数均 ≥200，timestamp 已转为 datetime。

### 2. 计算指标

对每个周期计算：EMA(20/50/200)、MACD(12,26,9)、RSI(14)、KDJ(9,3,3)、ATR(14)、布林带(20,2)。

公式与绘图实现：参见 [`CODE.md`](CODE.md)。

**完成标准**：两个周期上所有指标序列均已计算，无 NaN 污染最新一根 K 线。

### 3. 识别形态

基于价格峰谷几何关系识别：

- **反转**：头肩底/顶、双底/双顶、V 型反转
- **整理**：对称/上升/下降三角形、旗形、楔形
- **持续**：通道、矩形、持续型头肩

**完成标准**：每个周期至少命名 1 个形态并附置信度（高/中/低）；若无明确形态，显式写"无显著形态"，不要硬凑。

### 4. 评估共振

汇总前序步骤，给出 **共振度 0–5**：

| 共振度 | 信号一致情况 |
|--------|--------------|
| 0–1 | 信号混乱或相互矛盾 |
| 2–3 | 2–3 个维度同向 |
| 4–5 | 趋势+动量+形态+量全部同向 |

维度：EMA 排列方向、MACD 金/死叉+柱状方向、KDJ 超买超卖、形态突破方向、成交量确认。

**完成标准**：明确列出"支持主方向的信号"与"反对主方向的信号"两部分，共振度可由此直接数出。

### 5. 输出报告

必须包含以下章节（缺任意一项 = 未完成）：

- 概览（价格、24h 量、市场状态）
- 指标表（含 EMA 多空排列判断、布林带位置）
- 形态分析（1D 与 4h 分别列出）
- **共振度评估**（信号清单 + 综合评分）
- 关键价位（强/弱 支撑与阻力）
- 综合判断（主方向 + 入场参考 + 止损）

**完成标准**：所有章节齐全；1D 与 4h 结论冲突时，以 1D 为主方向并在报告中显式注明分歧。

## 指标解释规则

- **EMA 排列**：EMA20>EMA50>EMA200 = 多头排列；反向 = 空头；其余 = 混乱
- **RSI**：>70 超买，<30 超卖，其余中性
- **MACD**：MACD 上穿 Signal = 金叉（多），下穿 = 死叉（空）；柱状由负转正 = 动量转多
- **KDJ**：J>100 超买，J<0 超卖；K 上穿 D 且 J<20 = 底部金叉（强多信号）
- **布林带**：价格靠近上轨 = 偏强/超买，靠近下轨 = 偏弱/超卖；带宽收窄 = 变盘前兆
- **ATR**：用于止损参考，止损常设 1.5–2 × ATR

## 分支

以下两条路径为**可选分支**，触发条件未满足时不要执行。

### 分支 A：基本面叠加

**触发**：用户明确问宏观/消息面，或 `include_fundamental=true`。

用 `web_search` 查 "{symbol} news OR fundamental OR macro outlook {当前年份}"，将结论作为共振评估的额外维度（非技术信号），并在报告中单独成节。

### 分支 B：用户策略匹配

**触发**：用户提供了自定义交易规则（文字描述或规则文件）。

提取规则中的技术条件（如 "EMA 金叉 + RSI<30"），逐条比对当前市场状态，给出匹配度（满足/部分满足/不满足），并在综合判断中说明是否与当前共振方向一致。
