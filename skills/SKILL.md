# System Status Skill

当用户想要了解系统当前的全局状态时，使用此技能。

## 适用场景

- "现在系统状态怎么样？"
- "监控了哪些信号？"
- "交易框架在运行吗？"
- "现在有哪些 Agent 在工作？"
- "数据源正常吗？"
- "风控状态如何？"

## 使用方法

调用 `get_system_status` 工具，可指定 `section` 参数获取特定部分的状态：

| section | 说明 |
|---------|------|
| `all` | 返回全部状态（默认） |
| `agents` | 只返回 Agent 状态 |
| `frames` | 只返回交易/辅助框架状态 |
| `data_quality` | 只返回数据质量状态 |
| `skills` | 只返回技能清单 |
| `tools` | 只返回工具清单 |
| `signals` | 只返回信号监控状态 |
| `risk` | 只返回风控状态 |

## 返回内容说明

- **agents**: Supervisor 状态、已注册子 Agent 列表、意图路由配置
- **frames**: 交易框架、辅助框架、风控守卫、订单执行器的运行状态
- **data_quality**: 数据源完整性、延迟、异常统计
- **skills**: 已加载技能清单（全局技能 + Agent 专属技能）
- **tools**: 已注册工具清单及描述
- **signals**: 当前监控的信号流、Redis Stream 状态
- **risk**: 风控守卫状态、阈值配置、熔断器信息

## 输出格式

将工具返回的 JSON 数据格式化为可读的自然语言描述，向用户汇报系统状态。
