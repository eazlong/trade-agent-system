# 风控不变量

## 核心不变量

### I4: 账户余额非负
```
∀ account: account.balance ≥ 0
```
- 检查时机: 每次资金变动后
- 失败处理: 回滚事务

### I5: 订单数量非负
```
∀ order: order.quantity ≥ 0
```
- 检查时机: 订单创建时
- 失败处理: 拒绝订单

### I6: 价格非负
```
∀ order, trade: price ≥ 0
```
- 检查时机: 订单/交易创建时
- 失败处理: 拒绝操作

### I7: 资金守恒
```
∀ account: locked_funds ≤ available_funds
```
- 检查时机: 资金锁定时
- 失败处理: 拒绝锁定

## 风控阈值

| 参数 | 默认值 | 描述 |
|------|--------|------|
| `max_position_pct` | 10% | 单笔订单最大仓位占比 |
| `max_loss_pct` | 5% | 最大日损失占比 |
| `max_leverage` | 3x | 最大杠杆倍数 |
| `max_orders_per_minute` | 10 | 每分钟最大订单数 |

## 风控检查流程

```
订单创建 → 仓位检查 → 损失检查 → 杠杆检查 → 频率检查 → 执行/拒绝
```

## 风控违规处理

| 违规类型 | 处理方式 |
|----------|----------|
| 仓位超限 | 拒绝订单 |
| 损失超限 | 暂停交易 |
| 杠杆超限 | 调整仓位 |
| 频率超限 | 延迟执行 |
